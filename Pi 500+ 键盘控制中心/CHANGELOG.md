# Pi 500+ 键盘控制中心更新记录

本文档记录每个版本的功能新增、修复和行为变更。
早期记录根据现有源码、本机备份文件名和开发对话整理；已回退的尝试会明确标注。

## 1.1.17-portable — 2026-10-09

- KEY3 检测到待确认请求后立即在 LCD 显示 `Codex / Confirming...`，不再等确认命令和无障碍重试全部结束后才产生屏幕反馈。
- 确认真正完成后仍显示 `Codex / Confirmed`；超时或执行失败仍显示 `Confirm Failed`，避免提前误报成功。
- 运行状态在开始确认时立即写入 `confirming`，方便区分按键已接收与确认已完成。

## 1.1.16-portable — 2026-10-09

- 修复其他 Codex 对话使用 JSON 参数格式时，带引号的 `"sandbox_permissions":"require_escalated"` 无法被识别的问题。
- LCD 确认页面和键盘确认灯现在同时兼容带引号与不带引号的提权字段；`request_permissions` 与 `request_user_input` 的原有识别保持不变。
- 使用实际等待中的 SSH 提权确认记录进行跨对话回归测试。

## 1.1.15-portable — 2026-10-09

- 按用户要求撤回小屏幕亮度调节功能，控制中心不再显示亮度滑块。
- LCD 背光恢复为固定数字开关：亮屏时全亮，锁屏待机和程序退出时关闭，不再执行 PWM 或画面 RGB 调光。
- 移除亮度设置文件的读写与轮询，保留黑帧、Display Off、Sleep In 和像素位移等防残影功能。

## 1.1.14-portable — 2026-10-09

- 停用 GPIO24 软件 PWM，LCD 可见时背光改为稳定常亮输出，消除低亮度下的软件 PWM 闪烁。
- 保留 1%～100% 亮度滑块，改为在写入 RGB565 前等比例缩放整帧 RGB 像素；设置变化后立即重绘。
- 锁屏待机和程序退出时仍会关闭背光，并继续执行黑帧、Display Off 与 Sleep In。
- 该调节方式降低的是画面发光观感，不降低背光 LED 的实际耗电。

## 1.1.13-portable — 2026-10-09

- LCD 背光 PWM 频率由 800 Hz 提高到 4 kHz，减少低亮度下可见的背光闪烁。
- 滑块的 1%～100% 显示范围线性映射为实际 15%～100% 占空比，避免软件 PWM 产生过短、不稳定的低占空比脉冲。
- 保持 GPIO24、3.3V 电平和原有硬件连接不变，不涉及硬件改线。

## 1.1.12-portable — 2026-10-09

- 控制中心的 LCD 残影修复区域上方新增“小屏幕亮度”滑块，可在 1%～100% 之间实时调节 LCD HAT 背光。
- LCD 背光 GPIO 改为 800 Hz PWM 输出；待机仍保持完全关闭，唤醒时恢复用户设置的亮度。
- 亮度设置使用原子写入持久保存，LCD 服务每 0.2 秒检测变化，程序重启后保持上次亮度。

## 1.1.11-portable — 2026-10-09

- LCD 服务正常退出或重启时，先清空为黑帧，再执行 Display Off 与 Sleep In，最后释放背光、SPI 和 GPIO，避免最后一帧留在液晶层。
- 正常 Codex Usage 页面每 45 秒按右、下、左、上循环位移 1 像素；位移基于原始页面、不累计、不跨边缘回绕。
- Codex 确认页面和按键操作提示不参与像素位移，保持交互反馈稳定。

## 1.1.10-portable — 2026-10-09

- 小屏幕 5 Hour 和 7 Day 卡片底部的两个重置时间由灰色改为与卡片标题一致的白色。
- 额度数据过期时仍与卡片标题一起使用统一的弱化灰色，保留过期状态提示。

## 1.1.9-portable — 2026-10-09

- 摇杆切换信号源后的合并提示拆分为两个连续页面：先显示 `Switched / DisplayPort` 或 `Switched / HDMI`，再显示 `Keyboard / ON` 或 `Keyboard / OFF`。
- 键盘模式已经处于目标状态时仍显示第二页当前状态，但不会重复执行开启或关闭命令。
- 信号源成功而键盘联动失败时，第二页显示 `Keyboard / Failed`。

## 1.1.8-portable — 2026-10-09

- 修复树莓派仍锁定、Windows 经 `0502` 解锁后，再按锁定键误报 `Lock Failed / Windows Locked` 的问题。
- 锁定前先检查树莓派状态；已经锁定时跳过重复启动 swaylock，只向 Windows 重新发送 Win+L。
- 处理检查与启动之间的竞态：若期间锁屏已经出现，同样按成功处理，不再误报失败。

## 1.1.7-portable — 2026-10-08

- 使用 LCD HAT 摇杆切换到 DisplayPort 后自动开启蓝牙键盘模式，切换到 HDMI 后自动关闭键盘模式。
- 切换前先读取键盘模式状态；已经处于目标状态时不重复执行开启或关闭命令。
- 信号源切换成功但键盘联动失败时，小屏幕会明确显示 Keyboard Failed，避免把部分成功误报为全部失败。

## 1.1.6-portable — 2026-10-08

- 蓝牙键盘模式下新增 `0502` 加回车识别；序列只在键盘被转发到 Windows 时生效，不记录普通按键内容。
- 树莓派与 Windows 锁屏后识别到该序列，会让 LCD 小屏幕持续点亮，并恢复键盘模式的颜色、灯效与亮度，效果与树莓派解锁一致。
- 保留普通按键唤醒 10 秒的原有烧屏保护；下一次锁屏状态变化时自动清除本次持续点亮状态。

## 1.1.5-portable — 2026-10-08

- KEY3 改为优先立即发送 Codex 原生 Enter 批准快捷键，并在 0.8 秒内快速校验结果；正常确认不再等待 AT-SPI 扫描。
- 目标任务固定加载等待由 1.2 秒缩短到 0.55 秒，正常确认延迟降至约 1 秒。
- 仅当首次 Enter 未被接受时才调用 AT-SPI 辅助点击；辅助桥不可用时重新聚焦 Codex 并重试一次 Enter。

## 1.1.4-portable — 2026-10-08

- 修复 KEY3 打开目标任务后焦点停在侧栏按钮，导致 Enter 被侧栏控件吞掉而无法确认的问题。
- 优先通过 AT-SPI 无障碍树直接执行可见的“允许一次”按钮；辅助进程异常不会影响 LCD 主服务，找不到按钮时仍回退到 Codex 的 Enter 批准快捷键。
- 确认结果等待时间由 3 秒延长到 6 秒，并继续按原任务日志路径与 call_id 校验，避免多任务确认串线。
- 无论确认成功或失败，都恢复此前的前台应用；运行状态新增实际确认方式并清理过期错误。

## 1.1.3-portable — 2026-10-08

- 处理中动态灯效的状态图标由细线彩色圆环改为实心七彩渐变圆点，仅调整桌面显示，键盘灯效不变。

## 1.1.2-portable — 2026-10-08

- 修正 Qt 网格外边距被当成控件内部留白的问题；状态颜色及灯效模式按钮横纵间隔统一为 10 像素，避免圆角矩形相互贴合。

## 1.1.1-portable — 2026-10-08

- 修复 Qt 点击信号的布尔参数覆盖颜色按钮状态名称，导致点击模块异常退出的问题。
- 修复卡片内上下间距、居中及左右对齐、分组标题被遮挡，并恢复亮度滑杆数字显示。
- 后台线程通过 Qt 队列调度主线程定时器，定时器执行后释放；窗口隐藏后保持托盘运行，退出菜单明确结束程序。
- 验证实际按钮点击、连续 RGB 弹窗确认、灯效弹窗关闭及工作线程调度；硬件联动需在实际桌面会话核验。

## 1.1.0-portable — 2026-10-08

- 桌面控制中心从 Tkinter 迁移到 PyQt5，主窗口、卡片、按钮、滑杆、文本框、进度条和颜色/灯效弹窗均由 Qt 原生控件绘制。
- 四列布局、LCD 残影恢复命令及复制按钮改为真实圆角样式，不再受 Tk 原生直角容器限制。
- 保留蓝牙键盘模式、Codex 状态灯、灯效预览与自定义、额度和重置卡、AOC 信号源与亮度、托盘及全部后台线程逻辑。
- 增加轻量 Qt 兼容层，使已验证的硬件与状态逻辑无需重写；便携安装依赖由 `python3-tk` 改为 `python3-pyqt5`。

## 1.0.13-portable — 2026-10-08

- 两条 LCD 残影修复命令右侧增加小型复制图标；点击即可复制完整命令到系统剪贴板，并短暂显示绿色勾号反馈。
- 复制图标由 Tk 原生像素图绘制，不依赖额外图片文件或特殊符号字体。

## 1.0.12-portable — 2026-10-08

- 桌面控制中心的“显示器”标题改为“LCD HAT 与显示器”，副标题同步说明 LCD 残影恢复与 AOC 控制。
- 在显示器面板底部加入残影修复 30 分钟和 2 小时两条可选择复制的终端命令；命令路径根据实际安装目录自动生成，保持便携安装兼容。

## 1.0.11-portable — 2026-10-08

- 修复锁屏待机只关闭背光和显示、却保留最后一帧的问题；待机前先写入纯黑帧，再让 ST7789 执行 Display Off 和 Sleep In。
- 休眠期间停止周期性恢复帧和普通页面写入，唤醒时重新初始化控制器并完整刷新，降低圆角操作页形成图像残留的风险。
- 增加 LCD 残影恢复工具，使用无固定边缘的移动彩色渐变、反转灰阶和动态细纹持续活动全部像素；结束后自动恢复小屏幕服务。

## 1.0.10-portable — 2026-10-02

- 修复新版双 UUID 日志文件名被误识别为任务 ID，导致 KEY3 打开错误任务并出现恢复聊天失败的问题；优先读取 session_meta 中的真实任务 ID。
- 修复多个任务同时请求确认时，最新请求变化会被误判为原请求已确认的问题；按日志路径和 call_id 检查原请求。
- 更新 LCD 运行状态中的构建标识，方便核验已部署版本。

## 1.0.9-portable — 2026-10-02

- 桌面控制中心改为四列布局：Pi 500+ 蓝牙键盘、Codex 状态灯、Codex Usage 和显示器。
- 重新调整键盘模式灯光、亮度滑杆、配对控件和说明文字的间距，去掉突兀的底部留白。
- Codex Usage 独立显示 5 小时和 7 天额度，并读取真实的重置卡数量及每张卡的到期时间。
- 显示器改为独立列，信号源和亮度作为只读状态显示，保留切换信号源和亮度 ±5% 按钮。
- 保留现有灯效选择与 5 秒预览、托盘、开机自启动、小屏幕和全部实体按键逻辑。

## 1.0.8-portable — 2026-09-30

- 小屏幕上的 Codex 5 Hour 和 7 Day 额度进入新的重置周期时，百分比数字会平滑滚动到 100%。
- 小屏幕进度条与数字同步平滑增长至满格，5 Hour 与 7 Day 分别独立判断和播放。
- 仅当重置时间进入下一周期且额度明显回升时触发，普通刷新不播放动画。

## 1.0.7-portable — 2026-09-25

- 修复 Clash Verge/TUN 关闭期间 Codex 额度请求卡住，重新连接后仍长时间不刷新的问题。
- Codex `app-server` 请求增加 10 秒超时；超时后结束卡住的子进程并自动重建，避免无限阻塞后续请求。
- TUN 连通性从离线恢复为在线时，LCD 立即发起一次额度刷新，不再等待下一个 60 秒周期。

## 1.0.6-portable — 2026-09-24

- 主 IP 绿点从单一百度网站检测，改为并行检测华为联网检测、QQ 和淘宝三个中国大陆站点。
- 三个大陆站点任意一个成功即保持绿色；全部失败并连续两轮才变红，降低单一站点短暂波动造成的误报。
- 大陆站点检测使用最小化 GET 请求，避免部分站点对 HEAD 请求支持不稳定。
- 无 Wi-Fi/有线物理 IP 时仍立即显示红色；TUN 紫点仍需 Google 与 ChatGPT 均可访问，规则不变。

## 1.0.5-portable — 2026-09-24

- 修复执行 `systemctl --user restart codex-lcd-hat.service` 时，由 LCD 按键长按打开的 Clash Verge、ChatGPT 和键盘控制中心被一起结束或重启的问题。
- 原因是桌面应用由 LCD 服务直接创建，被 systemd 归入 `codex-lcd-hat.service` 的 control group。
- 桌面应用改为通过独立的临时用户服务启动，后续重启 LCD 服务不再影响已打开的应用。

## 1.0.4-portable — 2026-09-24

- 修复主 IP 绿点和 TUN IP 紫点在 240×240 低分辨率画布上边缘呈现不规整像素块的问题。
- 状态点改为 8 倍分辨率绘制后使用 Lanczos 缩小，保持原位置、尺寸和状态颜色不变。

## 1.0.3-portable — 2026-09-24

- 修复实际网络正常时，主 IP 绿点偶发短暂变红的问题。
- 经本机连续测试，`https://baidu.com` 裸域名的跳转连接会频繁超时，改为直接访问百度标准 HTTPS 主机 `https://www.baidu.com/`。
- 仍然只在百度网站可成功访问时显示绿色，并保留连续两次失败才变红的防抖逻辑。

## 1.0.2-portable — 2026-09-24

- 将早期变更按日期和功能阶段整理，并标明已回退的 UI 或调光尝试。

## 1.0.1-portable — 2026-09-24

## 1.0.0-portable — 2026-09-24

此版本是将以下开发阶段统一整理后的首个便携版。

### 2026-09-11：首次整合、LCD 与 AOC 控制

- 将 Pi 500+ 蓝牙键盘和 Codex RGB 键盘灯整合到同一个控制中心。
- 将 Codex 5 Hour / 7 Day 用量显示到 Waveshare 1.3inch LCD HAT。
- KEY1 用于切换 AOC 显示器信号源，后续增加防抖和快速按键响应。
- 修复小屏幕文字镜像和方向错误，改为横屏布局。
- 标题统一为 `Codex Usage`，去掉 Plus 和底部按键说明。
- 增加本机 IP、Codex 额度更新时间、进度条和重置时间。
- 调整进度条、刷新时间和底部留白的间距。
- 信号源切换改为全屏 `Switching` / `Switched` 反馈，完成后返回用量界面。
- 摇杆上下改为调节 AOC 显示器亮度，幅度最终确定为 5%。
- 优化 DDC/CI 亮度调节和信号源切换速度，并在控制中心同步显示 AOC 实际亮度。
- 加入 LCD 热插拔恢复与定时重绘，处理拔下后重插黑屏问题。
- 针对 GPIO 延长排线排查两排引脚交换、发热和 SPI 速率问题，最终恢复 40 MHz。
- LCD HAT 倒置使用后，画面旋转 180°，KEY1/KEY2/KEY3 映射改为 KEY3/KEY2/KEY1，摇杆方向同步翻转。
- 曾增加 LCD 背光调节，因低亮度 PWM 闪烁后完整移除，恢复固定背光。
- 统一桌面 UI 间距、颜色和字体，关闭按钮改为最小化到系统托盘。
- 开机自启和退出移至托盘右键菜单，删除原界面中的两个独立按钮。
- Codex 处理中状态由单一紫色改为彩色效果；状态描述会跟随实际选择的颜色名称。
- 蓝牙键盘状态卡调整为右上角 Windows 连接状态，并用红/绿颜色显示键盘模式关闭/开启。
- LCD 用量界面经过浅色和黑色两轮重设计，最终确定黑色横屏卡片布局。
- 网络指示点加入在线/离线颜色，用量与时钟刷新改为分层周期，避免每秒请求额度。

### 2026-09-12：锁屏、待机与时间显示

- KEY2 曾设置为同时锁定树莓派和 Windows，树莓派使用 `Ctrl+Alt+L`，Windows 使用 `Win+L`。
- 增加 Windows 端锁屏状态同步脚本和安装/卸载脚本。
- 树莓派与 Windows 都锁屏时，LCD 自动黑屏待机；任意一端解锁后重新点亮。
- LCD 右上角从本地当前时间改为 Codex 额度最后成功刷新时间。

### 2026-09-14：信号源摇杆与 Codex 确认

- 显示器输入名称统一为 `HDMI` 和 `DisplayPort`。
- 摇杆向左直接切换 DisplayPort，向右直接切换 HDMI。
- KEY3 改为 Codex 确认键，并支持在 Codex 不处于前台时后台确认。
- Codex 需要确认时，LCD 会全屏显示确认类型和具体原因。

### 2026-09-15：启动画面与键盘彩虹效果

- 修复开机初期 LCD 花屏，先隐藏背光，完成首帧后再显示。
- Codex 处理中状态增加键盘固件原生灯效：横向流动、上下流动、彩虹箭头、中心扩散、双向扩散、中心旋转、彩虹螺旋、彩虹信标、双旋彩虹和固定彩虹。
- 灯效选择器加入对应的颜色缩略图。
- 点击任意灯效可在键盘上预览 5 秒，结束后恢复当前 Codex 状态。

### 2026-09-16：断网时按键响应

- Codex 用量请求改为后台执行，网络不通时不再阻塞 GPIO 按键和摇杆。
