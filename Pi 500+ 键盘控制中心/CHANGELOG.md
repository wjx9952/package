# Pi 500+ 键盘控制中心更新记录

本文档记录每个版本的功能新增、修复和行为变更。
早期记录根据现有源码、本机备份文件名和开发对话整理；已回退的尝试会明确标注。

## 1.0.2-portable — 2026-09-24

- 根据现有备份和开发记录，补全 1.0.0 正式发布前的历史更新内容。
- 将早期变更按日期和功能阶段整理，并标明已回退的 UI 或调光尝试。

## 1.0.1-portable — 2026-09-24

- 新增摇杆上下调节 AOC 显示器亮度时的小屏幕全屏反馈。
- 开始调节时显示 `Adjusting` / `Brightness`。
- 松开摇杆后显示 `Adjusted` / `Brightness XX%`，其中数值为 AOC 返回的最终亮度。
- 修复长按摇杆连续调节时，完成提示被下一次 `Adjusting` 画面立即覆盖的问题。
- 建立版本管理规则：以后每次更新同步修改 `VERSION` 和本文档。

## 1.0.0-portable — 2026-09-24

此版本是将以下开发阶段统一整理后的首个便携版。

### 2026-09-11：首次整合、LCD 与 AOC 控制

- 将 Pi 500+ 蓝牙键盘和 Codex RGB 键盘灯整合到同一个控制中心。
- 将 Codex 5 Hour / 7 Day 用量显示到 Waveshare 1.3inch LCD HAT。
- KEY1 用于切换 AOC 显示器信号源，后续增加防抖和快速按键响应。
- 修复小屏幕文字镜像和方向错误，改为横屏布局。
- 标题统一为 `Codex Usage`，去掉 Plus 和底部按键说明。
- 增加本机 IP、Codex 额度更新时间、进度条和重置时间。
- 调整进度条、刷新时间和底部留白的间距。
- 信号源切换改为全屏 `Switching` / `Switched` 反馈，完成后返回用量界面。
- 摇杆上下改为调节 AOC 显示器亮度，幅度最终确定为 5%。
- 优化 DDC/CI 亮度调节和信号源切换速度，并在控制中心同步显示 AOC 实际亮度。
- 加入 LCD 热插拔恢复与定时重绘，处理拔下后重插黑屏问题。
- 针对 GPIO 延长排线排查两排引脚交换、发热和 SPI 速率问题，最终恢复 40 MHz。
- LCD HAT 倒置使用后，画面旋转 180°，KEY1/KEY2/KEY3 映射改为 KEY3/KEY2/KEY1，摇杆方向同步翻转。
- 曾增加 LCD 背光调节，因低亮度 PWM 闪烁后完整移除，恢复固定背光。
- 统一桌面 UI 间距、颜色和字体，关闭按钮改为最小化到系统托盘。
- 开机自启和退出移至托盘右键菜单，删除原界面中的两个独立按钮。
- Codex 处理中状态由单一紫色改为彩色效果；状态描述会跟随实际选择的颜色名称。
- 蓝牙键盘状态卡调整为右上角 Windows 连接状态，并用红/绿颜色显示键盘模式关闭/开启。
- LCD 用量界面经过浅色和黑色两轮重设计，最终确定黑色横屏卡片布局。
- 网络指示点加入在线/离线颜色，用量与时钟刷新改为分层周期，避免每秒请求额度。

### 2026-09-12：锁屏、待机与时间显示

- KEY2 曾设置为同时锁定树莓派和 Windows，树莓派使用 `Ctrl+Alt+L`，Windows 使用 `Win+L`。
- 增加 Windows 端锁屏状态同步脚本和安装/卸载脚本。
- 树莓派与 Windows 都锁屏时，LCD 自动黑屏待机；任意一端解锁后重新点亮。
- LCD 右上角从本地当前时间改为 Codex 额度最后成功刷新时间。

### 2026-09-14：信号源摇杆与 Codex 确认

- 显示器输入名称统一为 `HDMI` 和 `DisplayPort`。
- 摇杆向左直接切换 DisplayPort，向右直接切换 HDMI。
- KEY3 改为 Codex 确认键，并支持在 Codex 不处于前台时后台确认。
- Codex 需要确认时，LCD 会全屏显示确认类型和具体原因。

### 2026-09-15：启动画面与键盘彩虹效果

- 修复开机初期 LCD 花屏，先隐藏背光，完成首帧后再显示。
- Codex 处理中状态增加键盘固件原生灯效：横向流动、上下流动、彩虹箭头、中心扩散、双向扩散、中心旋转、彩虹螺旋、彩虹信标、双旋彩虹和固定彩虹。
- 灯效选择器加入对应的颜色缩略图。
- 点击任意灯效可在键盘上预览 5 秒，结束后恢复当前 Codex 状态。

### 2026-09-16：断网时按键响应

- Codex 用量请求改为后台执行，网络不通时不再阻塞 GPIO 按键和摇杆。
- 断网或用量接口超时时，信号源、亮度、锁屏和键盘模式仍能响应。

### 2026-09-19：桌面 UI 方案调整

- 曾按三栏侧边导航的参考图重设计整个控制中心。
- 用户确认不采用后回退到上一个稳定 UI，保留既有功能和布局。

### 2026-09-21：键盘模式灯光、TUN 与长按操作

- 键盘模式增加独立可自定义的常亮颜色。
- 键盘模式增加独立灯光亮度（1–255）调节。
- 关闭键盘模式后立即重新读取 Codex 状态并恢复对应灯效。
- 摇杆中键短按替代 KEY2 执行树莓派与 Windows 锁屏。
- 锁屏后键盘灯立即熄灭，解锁后按当前键盘模式或 Codex 状态恢复。
- KEY2 改为切换 Clash Verge 虚拟网卡（TUN）模式。
- 修复 TUN 只能关闭无法开启，以及与 Clash Verge 界面开关不同步的问题。
- 摇杆中键长按 5 秒可免密码重启 `display-manager`，锁屏界面也可执行。
- KEY1 长按打开或置顶 Pi 500+ 键盘控制中心。
- KEY2 长按打开或置顶 Clash Verge。
- KEY3 长按打开或置顶 ChatGPT。
- LCD 的 IP 下方增加 TUN IP 和 `TUN: ON/OFF`，文字颜色与主 IP 行统一。
- TUN IP 改为真实的 TUN 公网出口 IPv4，不再显示写死值或 `198.18.x.x` 内部地址。
- 修复额度卡片、百分比文字和图标被非等比例压扁的问题。
- 部署 LCD 程序改为只重启小屏幕服务，避免误重启整个桌面。
- 增加摇杆启动保护，避免服务刚重启时 GPIO 瞬时低电平被误识别为长按。

### 2026-09-22：锁屏唤醒、确认识别和多任务状态

- 树莓派锁屏后按任意内置键盘按键，LCD 和键盘灯唤醒 10 秒。
- 键盘模式开启时，锁屏唤醒恢复键盘模式颜色与亮度；关闭时恢复 Codex 状态灯。
- 修复锁屏后按键能唤醒 LCD 但键盘灯不亮的问题。
- 修复 RGB 颜色选择器中 Red/Green/Blue 数值无法手动编辑的问题。
- 重写 Codex 确认状态解析，恢复 LCD 需确认提示、键盘红灯和 KEY3 确认。
- 增加多个 Codex 窗口/任务同时运行时的聚合状态检测。
- 修复多窗口下 LCD 和灯光能提示确认，但 KEY3 无法将确认发送给正确任务的问题。
- Codex 闲置时键盘模式灯光才生效；Codex 处理中、需确认或完成后 1 分钟内，Codex 状态灯优先。
- 修复额度获取失败、确认监测和网络检查相互阻塞导致的偶发卡顿。

### 2026-09-23：网络指示与额度过期状态

- 将 TUN IP 前的指示点改为独立外网连通性状态，不通时显示红色。
- 主 IP 绿点以实际访问 `baidu.com` 为准，访问成功为绿色，失败为红色。
- TUN 紫点需要 `google.com.hk` 和 `chatgpt.com` 均可访问才显示紫色，任一失败则显示红色。
- 无 Wi-Fi 和有线网卡地址时，主 IP 显示 `--`，主指示点显示红色。
- 修复 Baidu 返回 HTTP 403 时被误判为断网，以及主网络短暂波动导致 TUN IP 被清空的问题。
- 增加连通性状态防抖，避免一次短暂超时就让绿点变红或清空 IP。
- Codex 额度超过 5 分钟未成功更新时，5 Hour 和 7 Day 卡片整体变灰，同时保留最后成功更新时间。

### 2026-09-24：Windows Caps Lock 原生高亮与 GitHub 发布

- 键盘模式下读取 Windows 发送的 Caps Lock LED 状态。
- Caps Lock 开启时使用 Pi 500+ 键盘固件原生的大写锁定高亮和颜色，其他按键保持当前键盘模式灯效。
- Caps Lock 关闭时所有按键恢复键盘模式当前灯光，修复其他按键闪烁蓝色的问题。
- 将当前可移植源码首次同步到 GitHub 仓库的 `Pi 500+ 键盘控制中心` 目录。
