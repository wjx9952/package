Pi 500+ 键盘控制中心
====================

当前版本：1.0.4-portable

每次功能新增、修复或行为调整时，必须同步更新 VERSION 和 CHANGELOG.md，
写明版本号、日期以及本次更新内容，再提交到 GitHub。

这个整合版把以下两个窗口合并为一个：

1. Pi 500+ 蓝牙键盘：配对、开启/关闭键盘模式、清除配对设备。
2. Codex RGB 键盘灯：状态颜色、各状态亮度、固件升级、自启动与托盘。
3. Codex 用量与显示器：5 小时/7 天额度、LCD HAT、AOC 信号源和亮度控制。

界面使用统一的 macOS 风格：浅灰窗口背景、白色卡片、系统蓝主按钮、统一字体
层级和状态颜色，不再使用左右割裂的深色/浅色主题。

安装方法：

    bash install.sh

安装时会弹出一次系统管理员确认，用于给现有蓝牙键盘后台增加 Win+L 命令；不会
删除或修改蓝牙配对记录。两个旧桌面入口会被移动到带时间戳的备份目录，并替换为
一个“Pi 500+ 键盘控制中心”入口。若之前已启用 RGB 程序自启动，整合后的程序会
继续自启动。

“处理中”状态可选择键盘固件自带的横向/上下流动、中心扩散、双向扩散、彩虹
箭头、中心旋转、螺旋、信标、双旋、固定彩虹等动态灯效。点击任一模式会立即在
键盘上预览 5 秒，随后恢复当前 Codex 状态；点击“应用”才会保存，也可使用自定义纯色

蓝牙键盘模式有独立的自定义常亮颜色与亮度（1–255）。键盘模式开启且 Codex 闲置时，
Windows Caps Lock 开启会让物理 Caps Lock 键稍亮；Codex 处理、确认和完成提示仍优先。
关闭键盘模式后会立即重新读取 Codex 状态并恢复对应灯效。

小屏幕的 Codex 用量请求在后台执行；断网时停止请求并显示离线状态，不会阻塞按键、
摇杆、锁屏或显示器控制。
常亮；状态颜色按钮和选择窗口会显示各灯效对应的图案或纯色色块。

LCD HAT 倒置安装后，KEY1 可随时开启或关闭蓝牙键盘模式。
持续按住 KEY1 满 2 秒会打开 Pi 500+ 键盘控制中心；若窗口已经打开，则将它置于最前面。
Codex 等待确认时，小屏幕会自动显示请求类型和具体原因；KEY3 用于后台确认该请求，
长按 KEY3 满 2 秒会打开或置顶 ChatGPT。确认完成后自动返回 Codex Usage 页面。倒置后的摇杆上下仍以 5% 调整 AOC 亮度。窗口中的
“切换信号源”和“亮度 ±5%”按钮可执行相同操作。
倒置后的摇杆向左直接选择 DisplayPort，向右直接选择 HDMI。
摇杆上下调节 AOC 亮度时，小屏幕先显示 Adjusting / Brightness；松开摇杆后
显示 Adjusted / Brightness XX%，展示最终实际亮度，然后返回 Codex Usage。
KEY2 用于切换 Clash Verge 的虚拟网卡（TUN）模式，小屏幕会短暂显示 TUN ON 或
TUN OFF；TUN IP 显示当前 TUN 流量的公网出口 IPv4，不显示 Mihomo 内部的
198.18.x.x 地址。长按 KEY2 满 2 秒会打开或置顶 Clash Verge。向下按压摇杆中键会向已连接的 Windows 发送 Win+L，并同时显示树莓派的
Ctrl+Alt+L 锁屏界面。使用摇杆中键锁屏无需安装额外
软件，且不要求先开启蓝牙键盘模式。持续按住摇杆中键满 5 秒则不会执行短按锁屏，
而是免密码运行 `sudo systemctl restart display-manager`；该长按在锁屏状态下仍然有效。

树莓派进入锁屏界面后，键盘灯亮度会立即降为 0；解锁后，若键盘模式开启则恢复其
自定义颜色和亮度，否则立即重新读取 Codex 状态并恢复对应灯效。
树莓派和 Windows 都锁屏后，小屏幕同时进入黑屏待机。锁屏期间按下内置键盘的
任意按键，小屏幕和键盘灯会唤醒 10 秒；键盘模式开启时恢复键盘模式灯效，关闭时
恢复当前 Codex 状态灯效。每次新的按键都会重新计时，10 秒后仍处于锁屏状态则再次
熄灭。

若要在树莓派和 Windows 都锁屏时自动关闭小屏幕，并在任意一端解锁时重新点亮，
请将 windows-lock-sync 文件夹复制到 Windows 后双击 install.cmd 安装状态同步任务。
